## About

I build products where **blockchain, artificial intelligence, and developer experience** intersect.
My work ranges from decentralized exchanges and on-chain markets to phone-native IDEs and language models.

```text
Shipping: AchSwap ecosystem, AI agents, and mobile-first developer tools
Exploring: DeFi, sparse models, cross-chain systems, and practical automation
```
